# Spaced Repetition System

Your brain forgets fast. This system fights that.

## The Schedule

After you first learn a topic or solve a problem, revise it after:

| Day | Action |
|---|---|
| Day 0 | Learn / solve |
| Day 1 | Quick recall |
| Day 3 | Dry run + key idea |
| Day 7 | Re-code pattern from memory |
| Day 15 | Solve 1 related problem |
| Day 30 | Teach out loud for 5 minutes |
| Day 90 | Mixed mock: 2 problems from this topic |

## How To Log

For every lesson or problem, write:

```text
Item: Sliding Window (longest substring without repeat)
Learned: 2026-08-04
Next: 2026-08-05, 2026-08-07, 2026-08-11, 2026-08-19, 2026-09-03, 2026-11-02
Status: Needs Revision / Solid / Mastered
```

## Daily Revision Block (20–30 min)

1. Open today's due items
2. For each item, answer without notes:
   - What is it?
   - Why does it exist?
   - Wrong thinking vs correct thinking
   - Complexity
3. If you fail any answer, reset that item to Day 1

## Quality Rule

Revision is not re-reading.

Revision is:

```text
Close the file → recall → check → fix gaps
```

## Priority Order When Busy

1. Items due today that you previously failed
2. Patterns from last mock interview mistakes
3. Hard topics (DP, Graphs, Binary Search on Answer)
4. Everything else
