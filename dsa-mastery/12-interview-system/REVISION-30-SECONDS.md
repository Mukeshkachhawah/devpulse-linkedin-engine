# Interview System — 30-Second Revision

**Clarify → Brute → Optimize → Code → Test**

1. Restate + constraints + example  
2. Name brute + O(?)  
3. Name pattern + optimal + O(?)  
4. Code with invariant  
5. Dry run + edges + final complexity sentence  

**Speak:** "Time is O(___) because ___. Extra space is O(___)."  

**If stuck:** smaller example → key property → pattern book tree.  

**Company:** tilt practice, but never skip the framework.
