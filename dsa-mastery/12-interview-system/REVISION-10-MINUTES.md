# Interview System — 10-Minute Revision

## 0:00–2:00 — Framework cold recite

Without notes, list the five phases and what belongs in each.  
Recite the micro-checklist from `mock-plan-and-final-checklist.md` section 9.

## 2:00–4:00 — Complexity drills

Say one-sentence time/space for:

1. Sliding window unique substring  
2. Dijkstra  
3. Size-k heap kth largest  
4. Memoized fib / climbing stairs  
5. Backtracking subsets  

Check against `complexity-communication.md`.

## 4:00–7:00 — STL cold write

Blank editor, write:

1. Min-heap of pairs  
2. Graph adj list + BFS  
3. Frequency map top scan  
4. `lower_bound` index on sorted vector  
5. Prefix sum array  

## 7:00–9:00 — Company + mock plan

- State your company's top 3 leans (`company-pattern-map.md`)  
- Pick tomorrow's mock from `interview-simulation-bank.md`  
- Write one LP/behavioral bullet if Amazon-style  

## 9:00–10:00 — Failure scripts

Practice saying out loud:

1. "Let me clarify constraints first..."  
2. "Brute force is ___, too slow because ___."  
3. "The key property is ___, so I'll use ___."  
4. "Dry run on this example..."  
5. "Time is O(___) because ___; space is O(___)."  

## Exit ticket

One improvement for the next mock (only one):
