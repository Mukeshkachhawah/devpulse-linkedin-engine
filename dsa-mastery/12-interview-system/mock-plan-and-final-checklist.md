# Mock Plan and Final Checklist

> How to rehearse like the real interview — and what to verify the night before / morning of.

---

## 1. Why Mocks Matter

Solving alone quietly ≠ interviewing.  
Mocks train: timing, talking, recovering from bugs, and ending cleanly.

Target: **≥ 8 full mocks** before onsite loops (more for career switches).

---

## 2. Mock Types

| Type | Length | Goal |
|---|---|---|
| Shadow mock | 45–60m | You narrate alone, record voice |
| Peer mock | 45–60m | Friend acts interviewer |
| Platform mock | 60m | Pramp / interviewing.io / coach |
| Phone screen sim | 30–45m | One medium, heavy communication |
| Onsite loop sim | 3–5 hours | Multiple rounds + breaks |

---

## 3. Standard 45-Minute Mock Script

```text
00:00–00:03  Intro + problem read
00:03–00:08  Clarify, examples, constraints
00:08–00:15  Brute + optimize + complexity
00:15–00:35  Code
00:35–00:42  Test + fixes
00:42–00:45  Complexity recap + questions
```

Interviewer (or you) should interrupt with:

- "What is the complexity?"  
- "Any edge cases?"  
- "Can you optimize space?"

---

## 4. 4-Week Mock Plan

### Week 1 — Framework muscle

- 3 shadow mocks (easy/medium)  
- Focus: clarify + brute named every time  
- Record and note dead air / jumping to code  

### Week 2 — Pattern pressure

- 3 mocks from weak patterns  
- Focus: pattern name in first 2 minutes  
- One graph + one DP + one window  

### Week 3 — Company tilt

- 3 mocks using `company-pattern-map.md` leans  
- Add one design/LP round if Amazon/Microsoft senior  

### Week 4 — Loop simulation

- 1 half-day multi-round  
- 2 polish mocks  
- Light review, sleep priority  

---

## 5. Scoring Rubric (Self-Grade 1–5)

| Axis | 1 | 3 | 5 |
|---|---|---|---|
| Clarifying | Jumps in | Some Qs | Restates + constraints |
| Problem solving | Stuck brute | Optimal with hints | Optimal + proof sketch |
| Coding | Buggy messy | Works few bugs | Clean, modular |
| Testing | None | Some cases | Edges + dry run |
| Communication | Silent | Patchy | Clear narrative |
| Complexity | Wrong/missing | Stated | Stated + justified |

**Pass bar for readiness:** average ≥ 4 across last 3 mocks.

---

## 6. After-Mock Review Template

Fill within 15 minutes:

```text
Problem:
Pattern I chose:
Pattern I should have chosen:
Where I lost time:
Biggest bug:
What I'll rehearse tomorrow (one item):
```

Keep a running "trap list" (max 20 lines).

## 7. Final Checklist — 48 Hours Before

### Skills

- [ ] Pattern Book 10-minute revision done  
- [ ] STL cheatsheet skimmed  
- [ ] 2 mediums timed with full narration  
- [ ] One rest day / light only  

### Logistics

- [ ] Interview time zone confirmed  
- [ ] Laptop charged + charger  
- [ ] IDE / CoderPad / HackerRank dry run  
- [ ] Camera, mic, headphones tested  
- [ ] Quiet room + backup hotspot  

### Mental

- [ ] Sleep plan (7–8 hours)  
- [ ] Stories ready (Amazon LP / behavioral)  
- [ ] Questions for interviewer written

## 8. Final Checklist — 60 Minutes Before

- [ ] Water + light snack  
- [ ] `REVISION-30-SECONDS.md` (Pattern Book + Interview System)  
- [ ] Close Slack/Discord/phone  
- [ ] Open blank editor / notepad  
- [ ] Deep breath; first goal = **clarify**, not code  

---

## 9. During-Interview Micro-Checklist

```text
[ ] Restate problem in one sentence
[ ] Ask n / edge constraints
[ ] Walk an example
[ ] State brute + complexity
[ ] Name pattern + optimal plan
[ ] Confirm with interviewer before coding
[ ] Code + narrate invariants
[ ] Dry run
[ ] Edges
[ ] Final complexity sentence
```

---

## 10. If Things Go Wrong

| Situation | Move |
|---|---|
| Blank 2 minutes | Re-read; solve a smaller example by hand |
| Bug spiral | Print invariant; test tiny case |
| Wrong pattern | Say so; switch; don't hide |
| Time almost up | Finish approach + complexity verbally; code core loop |
| Nervous voice | Slow down; shorter sentences |

Recovery script:

> "Let me reset with a smaller example and rebuild the invariant."

---

## 11. Post-Loop Notes (Same Day)

While memory is fresh:

1. Topics asked  
2. What went well  
3. What to drill  
4. Thank-you note if appropriate  

---

## 12. Wrong Thinking vs Correct

| Wrong | Correct |
|---|---|
| "I'll just solve 500 problems" | Mocks + review beats raw count |
| "Mocks only with hard problems" | Medium + communication first |
| "Cram the night before" | Light revision + sleep |
| "No dry run if confident" | Always dry run |
