# FAANG 24-Week Roadmap

Simple English. Hard training. C++ only for DSA practice.

## Weekly Time Target

- Ideal: 25–30 hours/week
- Minimum useful: 14–16 hours/week

## Daily Template

```text
Theory / lesson        45–60 min
Dry run + code pattern 30 min
Problems               90–120 min
Spaced repetition      20–30 min
Mock or contest        20–40 min
Log mistakes           10 min
```

## Contest Cadence

- Codeforces: 1–2 rounds/week from Week 5 onward
- AtCoder Beginner Contest: weekly when possible
- One virtual contest every Sunday from Week 8

## Mock Cadence

- Weeks 1–4: 2 short mocks/week (30–40 min)
- Weeks 5–12: 3 mocks/week
- Weeks 13–20: 4 mocks/week
- Weeks 21–24: daily short mock + 2 full 45-min mocks/week

---

## Phase A — Foundations and Core Patterns (Weeks 1–8)

### Week 1 — Complexity + Recursion + Math
- Lessons: `01-foundations/*`
- Patterns: recursion tree, base case thinking
- Problems: 20 easy/medium foundation drills
- Mock: explain Big-O of 3 snippets out loud

### Week 2 — Arrays + Prefix Sum
- Lessons: arrays, prefix-sum-difference-array
- Patterns: prefix sums, in-place transforms
- Problems: 25
- Contest: optional ABC

### Week 3 — Strings + Two Pointers
- Lessons: strings, two-pointers
- Patterns: opposite pointers, slow/fast on arrays
- Problems: 25
- Mock: 1 Medium timed

### Week 4 — Sliding Window + Matrix
- Lessons: sliding-window, matrix-problems
- Patterns: fixed/variable window
- Problems: 25
- Revision: Weeks 1–3 heavy review

### Week 5 — Linked Lists
- Lessons: `03-linked-lists/*`
- Patterns: reverse, merge, cycle detection
- Problems: 20
- Contest: start Codeforces Div. 2/3 participation

### Week 6 — Stacks + Queues
- Lessons: stack, queue-deque, expressions
- Patterns: matching, monotonic warm-up
- Problems: 22

### Week 7 — Monotonic Stack/Queue + Hashing
- Lessons: monotonic-stack-queue, `05-hashing/*`
- Patterns: next greater, frequency maps
- Problems: 25

### Week 8 — Checkpoint + Mixed Review
- Re-solve 40 prior problems blind
- 4 mocks this week
- Fill mastery levels L0–L5
- Goal: Arrays/Hash/LL/Stack at L3–L4

---

## Phase B — Trees, Graphs, Search (Weeks 9–14)

### Week 9 — Binary Trees
- Traversals, views, diameter, LCA warm-up
- Problems: 25

### Week 10 — BST + Heap + Trie
- Lessons: bst, heap-priority-queue, trie
- Problems: 25

### Week 11 — Graph Basics + BFS/DFS
- Representation, grid graphs, components
- Problems: 25

### Week 12 — Topo + Cycle + Shortest Path
- Kahn, Dijkstra, 0-1 BFS, Bellman-Ford decision tree
- Problems: 25

### Week 13 — DSU + MST + Advanced Graph
- Union-Find, Kruskal/Prim, multi-source BFS, bipartite
- Problems: 22

### Week 14 — Sorting + Binary Search
- Classic sorts, binary search on answer, quickselect
- Problems: 25
- Checkpoint: Trees/Graphs/Search at L3–L4

---

## Phase C — DP, Greedy, Backtracking (Weeks 15–19)

### Week 15 — DP Thinking + 1D DP
- Framework first, then climbing stairs family, house robber family
- Problems: 22

### Week 16 — Knapsack Family + Grid/String DP
- 0/1 knapsack, unbounded, LCS, edit distance, unique paths
- Problems: 25

### Week 17 — Interval / Bitmask / Tree DP
- Harder DP patterns
- Problems: 20

### Week 18 — Greedy + Backtracking
- Prove greedy carefully; subsets/permutations/combinations
- Problems: 25

### Week 19 — Mixed Hard Week
- Mixed Medium/Hard across DP/Graph/Search
- 5 mocks
- Goal: DP at L3+, favorites at L4

## Phase D — Advanced + Interview Mode (Weeks 20–24)

### Week 20 — Bits + Segment Tree + String Algos
- Lessons: `11-advanced/*`
- Problems: 20

### Week 21 — Pattern Book Mastery
- `13-pattern-book/*` end-to-end
- Recognition drills daily
- Decision-tree quizzes

### Week 22 — Interview System + Company Patterns
- `12-interview-system/*`
- Full communication practice
- 6 mocks minimum

### Week 23 — CP Peak + CS Fundamentals
- Contests + `14-competitive-programming` + `15-cs-fundamentals`
- OS/Networks/DB/Concurrency interview notes

### Week 24 — Final Polish
- `16-software-engineering`
- Re-solve top 100 weak problems
- Daily mocks
- Resume story + complexity communication drills
- Apply only if goals are mostly checked

## If You Fall Behind

Do not skip ahead to DP while arrays are weak.
Repeat the weak week.
Cut contest time before cutting revision.
Quality of 3 strong problems beats 10 copied solutions.
