# Start Here — Top-1% DSA + Engineering Curriculum

Welcome. This folder is not a random notes dump. It is a full training system.

## Who This Is For

You are a full-stack developer (NestJS, React, JavaScript, C++, Java).
Your goal is top-company interviews: Google, Microsoft, Amazon, Apple, NVIDIA, Anthropic, OpenAI, and similar firms.
You want deep DSA skill, not surface memorization.

## Language Choice (Locked)

**Use C++ for DSA.**

Why:

- You already know C++.
- Interview + contest templates are strongest in C++.
- STL (`vector`, `unordered_map`, `priority_queue`, `set`, `deque`) is enough for almost every interview.
- Java is backup only if a company forces it.

Do not restart DSA in Java first. That wastes months.

## Final Measurable Goals

Check these only when they are honestly true:

- [ ] Master 40+ DSA patterns
- [ ] Solve 500–700 carefully selected problems
- [ ] Complete 100+ timed mock interviews
- [ ] Reach Codeforces Expert or Candidate Master (optional but valuable)
- [ ] Consistently solve LeetCode Hard with a clear plan
- [ ] Explain any DSA topic to a 10-year-old
- [ ] Interview-ready for Google, Microsoft, Amazon, Apple, NVIDIA, Anthropic, OpenAI

## Daily Study Loop (3–5 hours)

```text
45–60 min  Read / revise one lesson section
30 min     Dry run + write C++ pattern from memory
90–120 min Solve 2–4 tracker problems
20–30 min  Spaced repetition cards
20–30 min  Mock prompt or contest problem
10 min     Log mistakes and next revision date
```

If you have only 2 hours:

```text
30 min lesson
60 min problems
20 min revision
10 min log
```

## Mastery Levels

For every topic, mark yourself:

| Level | Meaning |
|---|---|
| L0 | Never seen |
| L1 | Can explain to a child |
| L2 | Can dry-run an example |
| L3 | Can code pattern in C++ |
| L4 | Can solve Medium in 25–35 min |
| L5 | Can solve Hard / teach others / invent variants |

Target before applying to top companies: most core topics at **L4**, favorites at **L5**.
