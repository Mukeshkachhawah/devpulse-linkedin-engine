# Pattern Book — 10-Minute Revision

Use as a warm-up. Timer on. No phone.

## Minute 0–2: Recognition

Open `pattern-recognition-guide.md` section 13. Cover answers. Name the pattern for all 10 drills.

## Minute 2–5: Decision tree walk

Using `algorithm-decision-trees.md`, narrate out loud:

1. "Longest substring with k distinct" → branches you take  
2. "Network delay time" → branches  
3. "Split array largest sum" → branches  
4. "Median data stream" → branches  

## Minute 5–8: Cold templates (paper / blank editor)

Write only skeletons (no full problems):

1. Variable sliding window max length  
2. Kahn topo sort  
3. Binary search on answer (`ok`)  
4. Size-k min-heap kth largest  
5. Subsets backtracking  
6. Trie insert + search  

## Minute 8–10: Wrong → Right flash

Say corrections:

- DFS for unweighted shortest → **BFS**  
- Greedy for general coin change → **DP**  
- Nested loops on sorted pair sum → **Two pointers**  
- Word Search II with set only → **Trie**  
- Contiguous DP table when window works → **Window**  

## Exit ticket

Write one sentence for your weakest pattern:

> "I will recognize ___ when I see ___, and my first code shape is ___."

## Weekly add-on (optional +10 min)

Solve **one** medium from your weak pattern with full speak-aloud ritual.
