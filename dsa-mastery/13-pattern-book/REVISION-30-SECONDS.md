# Pattern Book — 30-Second Revision

Say this out loud before a mock:

1. **Contiguous + rule** → Sliding Window  
2. **Sorted pairs / ends** → Two Pointers  
3. **Unweighted shortest / levels** → BFS  
4. **Weighted shortest ≥ 0** → Dijkstra  
5. **Prereqs / order** → Topo  
6. **Merge groups** → Union-Find  
7. **Optimal / ways + overlap** → DP  
8. **Min X with ok(X) mono** → Binary Search Answer  
9. **Top-k / next best** → Heap  
10. **All configs** → Backtracking  
11. **Prefixes / dict words** → Trie  
12. **Tree combine kids** → Postorder; **levels** → BFS  

**Ritual:** Structure → Goal → Key property → Pattern → Complexity.
