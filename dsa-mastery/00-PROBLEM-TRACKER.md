# Problem Tracker (500+ Curated)

Simple English tracker. Solve by pattern, not by random scrolling.

## How to use

1. Pick problems from the current roadmap week.
2. Mark **Solved** = `Y` only if you can re-code without notes.
3. If you needed hints, mark **Needs Revision** = `Y`.
4. Update **Rev#** each time you revise (1, 2, 3...).
5. Prefer pattern coverage over vanity solve counts.

Columns: `# | Topic | Pattern | Problem | Diff | CompanyFreq | Week | Rev# | Solved | NeedsRev`

Diff: E = Easy, M = Medium, H = Hard

CompanyFreq: Very High / High / Med / Low (interview appearance signal)
