# Software Engineering — 30-Second Revision

Close notes. Speak aloud.

## Git

- Snapshots + branches; stage → commit → push.
- Prefer `revert` for shared undo; merge vs rebase tradeoffs.
- Never commit secrets.

## Debugging

- Repro → hypothesis → experiment → root fix → regression test.
- Sanitizers + bisect + oracle (brute).

## Profiling

- Measure hotspots; Amdahl; algo before micro.
- Flame graphs; watch p99.

## Testing

- Pyramid; AAA; edges; regression tests; coverage ≠ proof.

## Clean code

- Names, small functions, comments=why, YAGNI/DRY wisely.

## Patterns

- Strategy/Observer/Factory/Adapter/Decorator; Singleton sparingly.
- Encapsulate what varies; composition.

## Refactoring

- Same behavior, better structure; tiny tested steps; not rewrite.
