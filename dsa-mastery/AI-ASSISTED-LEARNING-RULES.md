# AI-Assisted Learning Rules (for Cursor)

Use AI as a tutor. Do not use AI as a solution vending machine.

## Always Do

1. Ask for intuition before code.
2. Ask for a dry run on a small example.
3. Ask for brute force vs better vs optimal comparison.
4. Ask for ASCII diagrams (memory, pointers, trees, graphs).
5. Ask how this lesson connects to previous lessons.
6. Ask for wrong thinking and why it fails.
7. Ask for interview wording: how would you explain this at Google?
8. After solving, ask: "What pattern was this?"
9. After solving, schedule revision: 1, 3, 7, 15, 30, 90 days.
10. Re-explain the solution in your own words without looking.

## Never Do

1. Never paste a problem and accept the first full solution blindly.
2. Never skip the "why does this exist?" step.
3. Never memorize code you cannot dry-run.
4. Never jump to optimal code before you can explain the slow way.
5. Never assume prior knowledge — ask AI to define every new word.
6. Never mark a topic "done" after one lucky solve.

## Good Prompts to Use

### When starting a topic

```text
Teach me [topic] using the 25-section lesson template.
Assume I have never seen it.
Use simple English.
Use C++ examples.
Include ASCII diagrams and a memory picture.
```

### When stuck on a problem

```text
Do not give me the full solution yet.
Ask me clarifying questions.
Help me classify the pattern.
Guide me from brute force to better to optimal.
```

### When revising

```text
Quiz me on [topic] like a Google interviewer.
Then quiz me like Amazon, Microsoft, and OpenAI.
Score my answers and tell me what to revise.
```

### When connecting ideas

```text
How is [topic A] connected to [topic B]?
Give me a decision tree for when to use each.
```

## Study Loop With AI

```text
1. Read the lesson file
2. Re-explain out loud (or write) in your own words
3. Dry-run one example by hand
4. Code the pattern in C++ without looking
5. Solve 2–4 problems from the tracker
6. Ask AI for a mock interview question
7. Log spaced repetition dates
```

## Integrity Rule

Top companies hire people who can think under pressure.
If AI writes every solution for you, you train dependency, not skill.
Use AI to sharpen thinking. You must still own the reasoning.
