## 5. Paanch data-backed ideas (detail)

### #1 — Financial calculators hub (India) — BEST START

- **Data proof:** Financial control ~27M/mo India; “how to make a budget” global ~713K; finance CPC $20–45.
- **Kya:** EMI, income tax (new vs old regime), in-hand salary (CTC → take-home), SIP returns, GST, home loan eligibility.
- **MVP:** 5 calculators + Hinglish explain + disclaimer; mobile-first; AdSense slots on result.
- **Hosting:** ₹500–1,500/mo. LLM ₹0 (pure JS formulas).
- **SEO:** Infinite variants — SBI/HDFC/ICICI EMI, FY 2025–26 tax, state GST, “salary calculator for X LPA”.
- **Money:** Finance ads + affiliate (loan/credit card) later optional.
- **Risk:** 3/10 — YMYL: formulas accurate + source + “not financial advice” disclaimer.

---

### #2 — Free invoice generator (global)

- **Data proof:** “how to create invoices” ~930K/mo global.
- **Kya:** Browser me invoice banao → PDF download → optional GST fields for India.
- **MVP:** Logo/upload, line items, tax, PDF export (client-side), no login first.
- **Hosting:** ₹500–1,000/mo. LLM ₹0.
- **SEO:** “free invoice generator”, “GST invoice template”, “freelance invoice maker”.
- **Money:** High — B2B/SaaS ads, dollar CPM; later Pro (save history).
- **Risk:** 3/10 — crowded, lekin long-tail + India GST wedge strong.

---

### #3 — Gold / silver rate today + city pages

- **Data proof:** “gold rate today” ~101M monthly India (navigational + price check).
- **Kya:** Today’s 22K/24K gold + silver; city pages (Delhi, Mumbai, Chennai…); optional jewellery cost calculator (making charges).
- **MVP:** Rate table + city pages + last updated time; cron refresh.
- **Hosting:** ₹1,000–2,500/mo (data feed + cron).
- **SEO:** “gold rate today [city]”, “22k gold rate”.
- **Money:** Jewellery + finance ads; daily return visitors.
- **Risk:** 5/10 — **data source** chahiye (public API/feed); stale rates = trust toot; competition heavy.

---

### #4 — Quick-commerce price compare (Blinkit vs Zepto vs Instamart)

- **Data proof:** Quick delivery searches ~29M, **+61% YoY** (Kantar).
- **Kya:** Same product (atta, milk, chips) → teen apps pe price + ETA compare.
- **MVP:** Manual curated basket compare pehle; baad me automation.
- **Hosting:** ₹2,000–8,000/mo if scraping/infra.
- **SEO / share:** WhatsApp “sasta kahan?” — viral potential.
- **Money:** Ads + possible affiliate; volume growing.
- **Risk:** 8/10 — **ToS / scrape fragile**; APIs rare; legal/ops heavy. Bootstrap pehle avoid better.

---

### #5 — “Who called me” spam number lookup (India)

- **Data proof:** “who called me” ~767K global; India me spam/OTP fraud pain strong; digital safety searches ~17M +9%.
- **Kya:** Number daalo → community reports (spam / bank / delivery); report button.
- **MVP:** Search + report + simple tags; moderation queue.
- **Hosting:** ₹1,000–3,000/mo (DB + mod time).
- **SEO:** “unknown number call”, “spam call India”.
- **Money:** Medium ads; telecom/VPN ads sometimes.
- **Risk:** 7/10 — **privacy + defamation**; false reports; IT Act / data rules careful; disclaimer + human mod zaroori.
