Full-stack is not React plus Node on your resume.

It is owning one user action from click to database and back.

A "done" UI with a fragile API is not shipped.
A solid API with a broken empty state is not shipped either.

When I call a feature full-stack complete, I check the path, not the stack:

- The UI shows loading, empty, success, and failure without guessing
- The API contract matches what the screen actually needs — no extra fields, no missing ones
- Auth and permissions are enforced on the server, not only hidden in the menu
- The write path is safe on double submit
- The read path stays correct after refresh, back navigation, and a cold cache
- Errors are visible to the user and searchable in logs
- One happy-path demo does not count as done

Frameworks change every year.

The path from click to data does not.

That path is the job.
