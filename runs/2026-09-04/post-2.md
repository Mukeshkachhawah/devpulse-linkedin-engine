Many bugs are not hard to fix.

They are hard to find.

When something breaks, do not start rewriting code first. First ask:

- What exactly failed?
- When did it start failing?
- What changed recently?
- Can I make the bug happen again on my machine?
- Which log or error points to the real place?

If you cannot answer these, fixing is mostly guessing.

Good debugging is slow at the start and fast at the end. Bad debugging is fast at the start and expensive later.

Find the real problem first. Then fix it once.
