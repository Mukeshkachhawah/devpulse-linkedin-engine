AI Engineering Path | Mathematics for AI — Vectors

A vector is an ordered list of numbers. In AI, almost everything becomes vectors.

A word, an image patch, a user profile — each can be turned into a list of features the model can compute on.

Key points:

- Vectors let us measure size and direction in feature space
- Similarity often means vectors pointing in a related way
- Embeddings are vectors that capture meaning from data
- Model layers repeatedly transform vectors into new vectors
- Clear vector thinking makes model inputs and outputs less mysterious

Takeaway:
If you understand vectors, you understand the common currency of modern AI systems.
