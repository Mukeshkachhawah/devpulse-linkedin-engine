Your AI assistant made you faster at writing code and slower at owning it.

The speed is real. The understanding is not.

You ship the feature. Tests pass. Then a week later something breaks in production and you open the file like it's someone else's code — because functionally, it is.

The bottleneck was never typing. It was always understanding.

Where AI quietly costs you:

- You accept a fix without knowing why the bug existed
- You paste a function you cannot rewrite from memory
- You debug by re-prompting instead of reading the stack trace
- You merge code whose edge cases you never traced yourself
- You lose the mental model that makes you useful in an incident

Speed without ownership is just borrowed time.

Use AI to write the first draft. Use your own head to earn the second.

If you cannot explain a line you shipped, you did not ship it — you forwarded it.
